Walltag pacman repository

Binary packages for Arch Linux. Source and packaging: github.com/dante-ferr/walltag.

Install

curl -fsSL https://dante-ferr.github.io/walltag/walltag.conf | sudo tee /etc/pacman.d/walltag
# Add this line to /etc/pacman.conf:
# Include = /etc/pacman.d/walltag

sudo pacman -Syu walltag

Packages live under x86_64/.
